Assignment 2 — Solution Design & Peer Review (Part A)

The Lost Amulet of Eldergrove · a web adventure game · Course: BTH012

1. Game description & gameplay

Theme. A great evil has stolen the Amulet of Eldergrove and hidden it in a dungeon. The player controls an adventurer (🧙) on a grid of tiles and must retrieve the Amulet and escape through the locked exit before health runs out.

Objective. Find the Amulet of Eldergrove (on the treasure tile) and escape through the Exit. The Exit is locked, so the player must first find the Key.

Rules.

  • The world is a 2D grid of Location objects; the player starts at (0,0), the Exit is at (7,7).
  • Walls block movement. Hazards damage: Monster 20 (0 with a Sword), Trap 10, Swamp 15.
  • The Exit is locked; stepping onto it with a Key consumes the Key and unlocks it; the player then wins if they carry the Amulet.
  • Win: reach the open Exit with the Amulet. Lose: health reaches 0. A Health Potion restores 30 HP.

Controls. Move WASD/arrows · pick up E/Enter · use item 1–4 · fullscreen F.

Screens. A welcome screen (objective + Start), a game screen (map, status, log), and an end screen (win/lose).

5. Game play loop

  1. Welcome — state welcome; show objective + controls.
  2. Start — Start calls game.start(); state becomes playing, game screen shown.
  3. Input — a keydown listener maps keys to commands: movement → game.move(direction); E/Enter → game.interact(); 1–4 → game.useItem(index); F → fullscreen.
  4. Update — the command mutates the model (position, health, inventory, world items); move() applies hazards, resolves the exit, checks win/loss.
  5. Render — renderWorld(), renderStatus(), renderLog() rebuild the DOM from the model.
  6. End — on won/lost the end screen appears; restart returns to welcome.

6. Advanced features & assumptions

  • Pseudo-random maps — generateRandomMap(width, height, rng) uses a seeded PRNG (unique, reproducible).
  • Persistence — persistence.js saves/loads game JSON via Node fs/promises.
  • Assumptions — rectangular grid (grid[y][x]); start (0,0), exit (width-1, height-1); items identified by name; no inline styles.
